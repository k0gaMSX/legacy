MSXCDEX.COM was written for use with Novaxis bios.
Unfortunately then not everyone uses that so the original won't work
with other bios'es.
MSXCDEX only uses the Novaxis bios to tell it at what I/O port the 
WD33C93A is located. Originally this was only port 34h but on later
Gouda versions they placed it at 24h and I think 1Ch because they got
the feeling that someone was copying the interface.

For those people who do not use Novaxis bios then I have made a patched
version of the MSXCDEX.COM which will default to I/O port 34h.

Just use MSXCDX2.COM instead of MSXCDEX.COM. Remember to read the manual!

If you get a newer version of MSXCDEX.COM then please let me know so that I
can patch that one too.
